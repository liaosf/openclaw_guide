## 🖥 一、接入企业微信指南

如果此时此刻您还不了解 OpenClaw（Clawdbot），或是了解但还没有部署 OpenClaw（Clawdbot），建议您先完成部署。

本文主要介绍（以腾讯云轻量应用服务器中部署 OpenClaw 为例）如何配置接入企业微信（WeCom）。

### 前提

在您正式开始为 OpenClaw（Clawdbot）配置企业微信前，请检查：

- 是否已经准备好了一个拥有管理员权限的企业微信企业。如尚未拥有满足条件的企业，可以参考创建&注册企业来创建一个新企业，以此来体验 OpenClaw 的能力。

⚠️ **注意：**
- 如果你的企业微信已经进行了企业认证，那么在后续配置 URL 时，必须要配置已经完成备案且备案主体和认证企业一致的域名。
- 如果你的企业微信尚未进行企业认证，那么可以在后续配置 URL 时，可先使用公网 IP 地址组成的链接来进行测试。

### 接入企业微信

**注意：** 本文目前针对从零开始配置聊天软件的情景。

#### 新建一个企业微信机器人

前往企业微信官网，使用有企业管理员权限的账号登录。如尚未拥有满足条件的企业，可以参考创建&注册企业来创建一个新企业，以此来体验 OpenClaw（Clawdbot）的能力。

在企业微信管理后台左侧导航依次找到并进入 `安全与管理 > 管理工具`，并且在页面内点击`创建机器人`。

滑到页面最底端点击`API模式创建`按钮：

在切换后的页面，依次填写名称、简介、可见范围、URL，并且点击随机获取按钮生成 Token 和 Encoding-AESKey（这是企业微信与 Moltbot 进行加密通信的密钥）。

⚠️ **注意：**
- 如果你的企业微信已经进行了企业认证，那么在后续配置 URL 时，必须要配置已经完成备案且备案主体和认证企业一致的域名。
- 如果你的企业微信尚未进行企业认证，那么可以在后续配置 URL 时，可先使用由 Lighthouse 公网 IP 地址组成的链接来进行测试。

#### 方式一：URL 配置为公网 IP 地址

此处我们以测试场景配置由 Lighthouse 公网 IP 地址组成的链接为例。需要关注，URL 处提及的"Lighthouse 实例 IP 地址"，可以把如下内容中的"Lighthouse 实例公网 IP 地址"替换为对应内容。

把复制好的公网 IP 地址（一串类似 12.12.12.12 的数字），替换到下面内容中：

```bash
http://Lighthouse实例公网IP地址:18789/wecom
```

**示例：** 比如你部署的 OpenClaw 服务器公网 IP 地址是 12.12.12.12，则可以在企业微信机器人的 URL 处填入：

```bash
http://12.12.12.12:18789/wecom
```

#### 方式二：URL 配置为已备案的域名

如果你已经拥有一个满足企业微信要求的域名（已经完成备案且备案主体和认证企业一致），假设你的域名已经解析到部署了 OpenClaw 的实例公网 IP，那么可以参考如下方式进行配置：

**说明：** 这里所说的"域名"，可以是已经备案的主域名（比如：jiayu.com）或这个已备案域名的子域名（比如：www.jiayu.com 或 abc.jiayu.com）。

在 URL 处填入 `http://你的域名:18789/wecom`，切记一定要带端口（默认为 18789）。

**注意：** URL 填写完成，获取 Token、Encoding-AESKey 后，先不要点创建，而是需要前往登录服务器后的页面，进行接下来的配置，完成后再返回企业微信机器人页面点击创建。

### 为 OpenClaw 配置 Channel

接下来需要为已经完成部署的 OpenClaw 配置 Channel（如企业微信，即 WeCom）。

进入腾讯云控制台，选中对应的 OpenClaw 服务器，点击实例卡片任意空白位置即可进入"管理实例"页面。

进入"应用管理"页签，可以看到相应的界面。

#### 模型配置

为 OpenClaw 配置模型 API Key，此处不再赘述。

#### Channel 配置（配置企业微信机器人 Token 和 EncodingAESKey）

**提示：** OpenClaw 支持同一台服务器配置多个 Channel，例如支持同时接入 QQ 机器人和飞书机器人。因此，如果当前正在配置的服务器之前已经接入了其他 Channel，也可以继续添加更多 Channel。

在 Channel 配置中，选择企业微信，然后依次在输入框内输入前文创建企业微信机器人时随机生成的 Token 和 EncodingAESKey。

填写完成后，点击面板下方的应用按钮，并在弹出的弹框中单击确定，稍等片刻，出现保存成功的提示后，即完成配置。

**提示：** 点击"应用"按钮完成 Channel 配置之后，当面版本的 Lighthouse 服务器应用管理页面中并不会展示已配置的 APP ID 和 App Secret。

### 完成企业微信机器人配置

此时我们再回到企业微信机器人创建页，点击创建按钮。

创建成功后，在接下来的页面中找到企业微信机器人的二维码，用手机扫码后添加。

添加完成后，无需配对即可在聊天窗中与它进行对话。

### 更多常用操作

#### 远程登录服务器

推荐您使用腾讯云默认的 OrcaTerm 远程终端来登录服务器，您也可以使用第三方软件（如 Xterminal、iTerm 等）来登录。

您可以使用腾讯云 OrcaTerm 远程终端登录服务器，并且在服务器的 Linux 操作系统中对 OpenClaw 执行各项更高阶的配置。

首先，前往轻量云 Lighthouse 控制台即可查看刚刚选购或重装完成的 OpenClaw 实例，点击页面内的登录按钮。

点击登录后，在腾讯云远程终端（OrcaTerm）的页面内，选择免密连接，点击登录即可。

通过远程终端 OrcaTerm 登录服务器成功之后的界面如下所示。

#### 设置后台运行 OpenClaw（可选）

如果您使用的 Lighthouse 应用模板为 2026.1.29 及更高版本，服务器创建之后，OpenClaw 默认会保持在后台运行，无需执行以下操作。

为了避免关掉服务器远程终端（OrcaTerm）之后就无法与 bot 对话，可以参考以下教程实现让 OpenClaw 保持在后台持续运行。

问题的原因是因为前面步骤中运行的命令，都只是"临时运行"，所以这里我们需要在前置的配置完成后，让 OpenClaw（Clawdbot）运行在后台，这样的话我们关掉服务器命令行页面（OrcaTerm）后就不会和它失去联系了。

首先在远程终端（OrcaTerm）中，操作键盘按下 `Ctrl + C`（Linux 系统），终止前文运行的命令，回到如下图所示的状态。

依次向命令行内粘贴并运行以下命令：

```bash
loginctl enable-linger $(whoami) && export XDG_RUNTIME_DIR=/run/user/$(id -u)
```

这一步运行完之后不会有任何返回，这是正常的。

继续往下，运行下一步的指令：

```bash
clawdbot daemon install
```

运行完成之后的效果如下。

接着往下：

```bash
clawdbot daemon start
```

最后一步：

```bash
clawdbot daemon status
```

如果运行完这个脚本出现如下效果，那么说明配置成功了。

之后你就可以放心关掉服务器命令行（OrcaTerm）页面，尽情享受和 OpenClaw 的交流了。

## 🖥 二、接入 QQ 指南

如果此时此刻您还不了解 OpenClaw（Clawdbot），或是了解但还没有部署 OpenClaw（Clawdbot），建议您先完成部署。

本文主要介绍（以腾讯云轻量应用服务器中部署 OpenClaw 为例）如何配置接入 QQ 机器人。

### 前提

在您正式开始为 OpenClaw（Clawdbot）配置企业微信前，请检查：

- 您是否已经拥有一个完成实名认证的腾讯 QQ 账号。

### 接入 QQ

**注意：** 以下步骤针对已在腾讯云 Lighthouse 服务器中部署 OpenClaw，从零开始配置接入 QQ 的情况，如果有部分步骤已完成，可酌情跳过。

#### 注册 QQ 开放平台

前往腾讯 QQ 开放平台官网，默认无法使用您的 QQ 账号直接登录，需要新注册 QQ 开放平台账号。

首次注册之后，可以按照 QQ 开放平台的指引设置超级管理员。

手机 QQ 扫码成功后，继续下一步填写主体相关信息。此处以"个人"为例，按照指引依次输入姓名、身份证号、手机号、验证码，点击继续进入下一步人脸认证。

使用手机 QQ 扫码进行人脸认证。

人脸识别审核通过后，即可登录进入 QQ 开放平台。

#### 创建一个 QQBot 机器人

在 QQ 开放平台的 QQ 机器人页面，可以创建机器人。

QQ 机器人创建完成之后，可选择机器人点击进入管理页面。

在 QQ 机器人管理页面获取当前机器人的 AppID 和 AppSecret，复制并将其保存到个人记事本或备忘录中（请注意数据安全，勿泄露），后续在"为 OpenClaw 配置 QQ 机器人 AppID 和 AppSecret"步骤中需要使用。

**注意：** 出于安全考虑，QQ 机器人的 AppSecret 不支持明文保存，首次查看或忘记 AppSecret 需要重新生成。

#### 沙箱配置

在 QQ 机器人的"开发管理"页面，在"沙箱配置"中，设置单独聊天（选择"在消息列表配置"）。您可以按照自己的使用场景进行配置，也可以完成后续步骤之后再回到本步骤进行操作。

⚠️ **注意：**
- 此处已创建的 QQ 机器人无需进行发布上架对所有 QQ 用户公开使用，在开发者私人的（沙箱）调试下使用体验即可。
- QQ 开放平台不支持机器人的"在 QQ 群配置"操作，只支持单独和 QQ 机器人聊天。

**注意：** 选择"在消息列表配置"时，需要先添加成员，再通过该成员的 QQ 扫码来添加机器人。

此处注意添加成员成功之后，还需要使用 QQ 扫码添加。

此时您的 QQ 账号添加机器人之后，还不能与该机器人正常进行对话，会提示"该机器人去火星了，稍后再试吧"，因为 QQ 机器人此时尚未与 OpenClaw 应用打通。您需要继续后面的步骤，为 OpenClaw 应用配置 QQ 机器人的 AppID 和 AppSecret。

（可选）您也可以参考前述步骤添加更多成员：首先在成员管理页面中添加新成员，然后在沙箱配置页面中添加成员，之后新成员即可通过 QQ 扫码添加该 QQ 机器人。

### 为 OpenClaw 配置 Channel

接下来需要为已经完成部署的 OpenClaw 配置 Channel（如 QQ）。

进入腾讯云控制台，选中对应的已部署 OpenClaw 的 Lighthouse 服务器，点击服务器卡片进入"管理实例"页面。

#### 模型配置

为 OpenClaw 配置模型 API Key，此处不再赘述。

#### Channel 配置（配置 QQ 机器人 App ID 和 App Secret）

进入"应用管理"页签，在"Channel 配置"输入框，输入在前面步骤中获取的 QQ 机器人 App ID 和 App Secret，并点击应用并确定操作，等待几十秒后页面提示"保存成功"即完成配置。

**提示：** OpenClaw 支持同一台服务器配置多个 Channel，例如支持同时接入 QQ 机器人和飞书机器人。因此，如果当前正在配置的服务器之前已经接入了其他 Channel，也可以继续添加更多 Channel。

**提示：**
1. 点击"应用"按钮完成 Channel 配置之后，当面版本的 Lighthouse 服务器应用管理页面中并不会展示已配置的 APP ID 和 App Secret。
2. 如果在和 QQ 机器人对话时，回复"该机器人去火星了，稍后再试吧"，原因也可以是因为未正确配置 App ID 和 App Secret，可以重试。

模型配置和 Channel 配置都完成之后就初步完成了 OpenClaw 配置，在手机 QQ 和电脑版上均可以开始与已接入 OpenClaw 的 QQ 机器人进行聊天。

### 在 QQ 中与 QQ 机器人互动

配置 QQ 机器人的 App ID 和 App Secret 之后，您可以在 QQ 软件中尝试和已经打通 OpenClaw 的 QQ 机器人进行单独聊天。如果 QQ 机器人能够以 AI 的方式对话，则说明您已经成功完成 OpenClaw 应用接入 QQ 机器人。

接下来您就可以开始进一步解锁 OpenClaw 接入 QQ 机器人之后的更多使用场景。例如，创建两台部署 OpenClaw 并且接入同一个 QQ 机器人。

## 🖥 三、接入飞书指南

如果此时此刻您还不了解 OpenClaw（Clawdbot），或是了解但还没有部署 OpenClaw（Clawdbot），建议您先完成部署。

本文主要介绍（以腾讯云轻量应用服务器中部署 OpenClaw 为例）如何配置接入飞书机器人。

### 前提

在正式开始为 OpenClaw(Clawdbot) 配置接入飞书机器人之前，请您检查：

- 您是否已经拥有一个飞书账号。

### 接入飞书

**注意：** 以下步骤针对已在腾讯云 Lighthouse 服务器中部署 OpenClaw，从零开始配置接入飞书的情况，如果有部分步骤已完成，可酌情跳过。

#### 创建飞书企业自建应用

首先，您需要使用您的飞书账号登录飞书开放平台。登录成功后，点击创建企业自建应用。

填写应用名称（如 "OpenClaw 助手"）、应用描述，选择应用图标，点击创建按钮，进入应用管理页面。

#### 添加机器人

在前一步所创建应用的管理页面，左侧导航栏中找到并点击`添加应用能力`，在弹出的列表中选择`机器人`，点击`添加`。

**提示：** 添加机器人之后，可以暂不发布，待其他配置完成后一并发布。

#### 查询 AppID 和 AppSecret

在左侧导航栏找到 `凭据与基础信息`，点击进入。在页面中找到 `App ID` 和 `App Secret` 两个参数，分别点击右侧 `复制` 按钮，将其保存到个人记事本或备忘录中（注意数据安全，勿泄露），后续步骤中需要使用。

### 为 OpenClaw 配置 Channel

接下来需要为已经完成部署的 OpenClaw 配置模型和 Channel（如飞书）。

进入腾讯云控制台，选中对应的已部署 OpenClaw 的 Lighthouse 服务器，点击服务器卡片进入"管理实例"页面。

#### 模型配置

为 OpenClaw 配置模型 API Key，此处不再赘述。

#### Channel 配置（配置飞书机器人 App ID 和 App Secret）

进入"应用管理"页签，在"Channel 配置"输入框，选择"飞书"，输入前面步骤中查询到的飞书机器人的 App ID 和 App Secret，并点击应用并确定执行操作，等待几十秒后页面提示"保存成功"即完成配置。

**提示：** OpenClaw 支持同一台服务器配置多个 Channel，例如支持同时接入 QQ 机器人和飞书机器人。因此，如果当前正在配置的服务器之前已经接入了其他 Channel，也可以继续添加 Channel。

**提示：** 点击"应用"按钮完成 Channel 配置之后，此处的应用管理页面中并不会展示已配置的 APP ID 和 App Secret。

### 飞书机器人相关配置

#### 事件配置

在飞书应用管理页，左侧导航栏找到 `事件与回调`，点击进入页面。在"事件配置"页签中选择 `长连接接收事件`，点击保存。

⚠️ **注意：** 如果这一步报错提示"未建立长连接"，请检查自己的 App ID 和 App Secret 是否已正确配置。

点击该页面中的 `添加事件`，在弹出的事件列表中，选择 `消息与群组` 分类，勾选 `接收消息`，点击 `确认添加`，按照指引确认开通权限。

完成事件配置后，可以在当前页面中查看到已添加事件。

#### 回调配置

在"事件与回调-回调配置"页面中，订阅方式选择 `使用长连接`，点击保存，无需填写其他地址，配置自动生效。

#### 权限配置

在飞书应用管理页，左侧导航栏找到 `权限管理`，点击进入页面。点击页面中的 `批量导入权限` 按钮，弹出权限导入窗口。

复制以下代码，替换前面弹窗中原有的 JSON 内容，点击下一步，确认新增权限，继续申请开通，确认后等待权限导入完成。

```javascript
{
  "scopes": {
    "tenant": [
      "contact:user.base:readonly",
      "im:chat",
      "im:chat:read",
      "im:chat:update",
      "im:message",
      "im:message.group_at_msg:readonly",
      "im:message.p2p_msg:readonly",
      "im:message:send_as_bot",
      "im:resource"
    ],
    "user": []
  }
}
```

权限列表中出现以下已导入的权限，即为配置完成。

#### 创建版本并发布

在飞书应用管理页，左侧导航栏找到 `版本管理与发布`，点击进入页面。点击右上角的创建版本。

填写应用版本号（此处以 1.0.0 为例，您可以自行定义版本号）和更新说明，点击保存并确认发布。

发布成功后，可以在"版本管理与发布"页面，查看到已经发布的版本号和状态。

### 如何将机器人添加进飞书群聊/私聊

以电脑版飞书软件为例（手机端飞书的操作类似），登录飞书后，点击搜索框。

在搜索框中输入前面步骤中创建并发布的飞书机器人的应用名称，输入回车进行搜索。

单击搜索到的机器人，进入私聊页面，即可开始与已经接入 OpenClaw 的飞书机器人进行对话。

对于群组聊天的场景，可以点击飞书搜索框上方的加号，选择创建群组，并完成创建。

进入新创建的群组，点击右上角的设置。

在设置中选择"群机器人"，点击"添加机器人"。

在上方搜索框搜索您创建的机器人的应用名称。

选择您之前创建的机器人后，点击添加即可将飞书机器人加入群聊。

到这里就初步完成了配置，在手机版飞书和电脑版飞书上均可以开始与已经接入 OpenClaw 的飞书机器人进行聊天。

接下来您就可以开始进一步解锁 OpenClaw 接入飞书机器人之后的更多使用场景。

## 🖥 四、接入钉钉指南

如果此时此刻您还不了解 OpenClaw（Clawdbot），或是了解但还没有部署 OpenClaw（Clawdbot），建议您先完成部署。

本文主要介绍（以腾讯云轻量应用服务器中部署 OpenClaw 为例）如何配置接入钉钉机器人。

### 前提

在正式开始为 OpenClaw(Clawdbot) 配置接入飞书机器人之前，请您检查：

- 您已经拥有一个具有企业管理员权限的钉钉账号。

### 接入钉钉

**注意：** 以下步骤针对已在腾讯云 Lighthouse 服务器中部署 OpenClaw，从零开始配置接入钉钉的情况，如果有部分步骤已完成，可酌情跳过。

#### 申请钉钉应用

前往钉钉开发者平台（需有管理员权限）：https://open-dev.dingtalk.com/fe/app?hash=%23%2Fcorp%2Fapp#/corp/app

点击`创建应用`

选`机器人`

完成所有必填项（其他默认）

点击`查看版本详情 >> 编辑`

完成所有必填项后点击保存，在弹出的窗口点击`确认发布`

点击`凭证与基础信息`保存好 Client ID 与 Client Secret。

### 为 OpenClaw 配置 Channel

接下来需要为已经完成部署的 OpenClaw 配置模型和 Channel（如钉钉）。

进入腾讯云控制台，选中对应的已部署 OpenClaw 的 Lighthouse 服务器，点击服务器卡片进入"管理实例"页面。

#### 模型配置

为 OpenClaw 配置模型 API Key，此处不再赘述。

#### Channel 配置（配置钉钉机器人 Client ID 与 Client Secret）

进入"应用管理"页签，在"Channel 配置"输入框，输入在前面步骤中获取的 Client ID 与 Client Secret，并点击应用并确定操作，等待几十秒后页面提示"保存成功"即完成配置。

**提示：** OpenClaw 支持同一台服务器配置多个 Channel，例如支持同时接入钉钉机器人和飞书机器人。因此，如果当前正在配置的服务器之前已经接入了其他 Channel，也可以继续添加 Channel。

**提示：**
点击"应用"按钮完成 Channel 配置之后，当面版本的 Lighthouse 服务器应用管理页面中并不会展示已配置的 APP ID 和 App Secret。

模型配置和 Channel 配置都完成之后就初步完成了 OpenClaw 配置，在手机版和电脑版钉钉上均可以开始与已接入 OpenClaw 的钉钉机器人进行聊天。

### 在钉钉中与钉钉机器人互动

配置钉钉机器人的 Client ID 与 Client Secret 之后，您可以在钉钉软件中尝试和已经打通 OpenClaw 的钉钉机器人进行单独聊天。如果钉钉机器人能够以 AI 的方式对话，则说明您已经成功完成 OpenClaw 应用接入钉钉机器人。
